# SAMY

SAMY is our Houdini project for TU Delft’s Computational Design Studio (BK7956). We’re building a tool that turns editable site footprints into voxel massing studies.

## Getting started

Run `git lfs install` before cloning the repo. Once the Houdini scene is added, open it from the root of your clone. Keep paths to shared inputs relative to `$HIP` so the scene works on everyone’s machine.
